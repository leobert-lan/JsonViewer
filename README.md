# JSON Log Viewer

一款基于 Python + tkinter 的桌面工具，用于解析并可视化日志中嵌套的 JSON 字符串。

---

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 自动预处理 | 自动剥离日志前缀/后缀、去除多余换行、反转义 `\"` |
| `\xHH` 解码 | 将连续的十六进制转义序列还原为 UTF-8 可读字符（如中文） |
| 树形展示 | 以折叠/展开的树状结构展示 JSON 键值、类型与值 |
| 全部展开/收起 | 一键展开或折叠所有节点 |
| 错误定位 | 解析失败时弹窗高亮标注出错位置，方便排查 |
| 双击复制 | 双击任意叶节点，自动将其值复制到系统剪贴板 |
| 快捷键 | `Ctrl + Enter` 快速触发解析 |

---

## 🖥️ 运行环境

- Python **3.10+**（使用了 `str | None` 联合类型注解）
- 仅依赖 Python 标准库（`tkinter`、`json`、`re`），**无需额外安装第三方包**

## 🚀 快速开始

### 直接运行

```bash
python json_viewer.py
```

### 打包为 exe（Windows）

```powershell
.\build.ps1
```

打包完成后，可执行文件位于 `dist\JSON日志查看器\JSON日志查看器.exe`。

---

## 📖 使用说明

1. 启动程序后，将包含 JSON 的日志文本粘贴到顶部输入框。
2. 点击 **▶ 解析 JSON** 按钮（或按 `Ctrl+Enter`）开始解析。
3. 解析结果以树形结构显示在下方面板，节点列出：
   - **键 / 索引**
   - **类型**（`string` / `number` / `bool` / `null` / `object` / `array`）
   - **值**
4. 双击叶节点可将其值复制到剪贴板。
5. 使用 **全部展开 / 全部收起** 按钮控制树形显示层级。
6. 点击 **清空** 可重置输入与树形视图。
